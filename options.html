📌 Getting Started

Pin the extension for quick access: click the 🧩 puzzle icon in your browser toolbar, then click the pin next to Senior SafeSurf.

🎯 How Blocking Works

Keyword — Type instagram to block instagram.com, instagram.net, etc.
Domain — Type facebook.com to block only that site.
Path — Type youtube.com/shorts to block only that section.

🔐 Security Tip

Go to Security & Password to set a master password. This prevents anyone from removing your blocks.

AI Protection

Keywords alone can't tell a museum page about guns from a gun shop. The AI reads the page around a blocked word, and spots scams that no word list catches. It runs on this computer first.

Where the AI runs

On-device AI (Gemini Nano)

Checking…

Cloud check (Gemini via Firebase)

Allow cloud checks Only a small snapshot is sent: the site name, page title, headings and about 600 characters around the match. Never passwords, form contents or the full address. Used when the on-device AI is missing or unsure.

Fine-tuning

Sensitivity Strict keeps more keyword blocks and warns sooner. Relaxed lets the AI clear more harmless mentions.
Scam check on login and payment pages Also checks pages that ask for a password or card number, even without a blocked word, and warns about likely scams.
Use Firebase Remote Config Optional. Lets the maintainers tune the cloud model, the escalation threshold and the prompt, or switch the cloud off, without a store update.
