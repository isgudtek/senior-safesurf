Why we built it

The internet targets older adults. Their tools don't fit them.

Older adults are one of the fastest-growing groups online, and the group that loses the most when something goes wrong. Parental controls are built for children, security suites for IT departments, and word lists block too much while missing the scams that matter.

Hybrid AI

On the computer first. The cloud only when needed.

Built on the Firebase AI Logic hybrid SDK. Every check uses the same verdict schema on both engines, and every answer says which one gave it.

🔒 LOCAL Gemini Nano

Runs inside Chrome on the computer. Private, offline and free, so it can check every page a parent visits without sending anything anywhere.

☁️ CLOUD Gemini via Firebase

Only with the user's consent, and only when Nano is missing or unsure. It sees a small snapshot (site, title, headings and about 600 characters), never passwords, forms or the full address.

Blocked word or login page→ Page covered, snapshot built→ 🔒 Nano decides→ ☁️ Cloud if unsure→ Block · Warn · Allow
What it does

Big buttons. One question. Plain answers.

Blocks with a reason

A blocked word is judged in context first. When a page is blocked, it says why, and where it was checked.

Warns about scams

Login and payment pages get a background check. A fake bank alert gets a large, clear warning and a one-click "Block this site".

"Is this page safe?"

One click in the popup or on the on-page toolbar, next to the text-size buttons. The answer shows Local AI or Cloud AI.

Family summary

A weekly log with a plain-language AI summary. Optional sharing with a son, daughter or carer through Firebase Authentication and Firestore.

The user decides

Off, On this computer only, Hybrid or Cloud only, explicit cloud consent, sensitivity, and a "Try it" box.

Set up in one screen

The welcome screen checks the computer, starts the one-time Gemini Nano download, and explains clearly when a computer can't run it.

Install

Ready in two minutes

Download

senior-safesurf.zip and unzip it. You get a senior-safesurf folder.

Open extensions

In desktop Chrome, go to chrome://extensions and turn on Developer mode (top right).

Load it

Click Load unpacked and choose the senior-safesurf folder.

Start protecting

On the last welcome slide, allow cloud checks if you like and press Start protecting. No accounts or keys needed.

Cloud checks use App Check with reCAPTCHA Enterprise. Use a normal Chrome window; automated or headless browsers may be rejected. Developers: build it from source with npm install && npm run build (see the README).
